# Kayros Center Villavicencio - Sitio Web Oficial

Portal web oficial y centro de recursos de la **Iglesia Cristiana Kayros Center** en Villavicencio, Colombia. Pastores principales: **Rev. Mauricio Silva** y **Ps. Diana Pérez**.

## 🚀 Características del Sitio
- **Diseño Editorial Clean UI:** Interfaz minimalista y moderna con estética monocromática.
- **Centro de Recursos:** Acceso al taller interactivo de Finanzas Bíblicas y Escuela de Teosuperación.
- **Taller Interactivo de Finanzas:** Calculadora en vivo *Pan vs. Semilla*, detector de *gastos hormiga*, autodiagnóstico de 7 preguntas y generador de reporte para imprimir en PDF.
- **Escuela de Teosuperación:** Estructura de los 8 niveles de estudio bíblico.
- **Grupos de Conexión:** Buscador de grupos por comunas y barrios de Villavicencio.
- **Videoteca & Mensajes:** Reproductor interactivo integrado con YouTube.
- **Optimización:** SEO estructurado con Schema.org y etiquetas geo-localizadas para Villavicencio.

## 🛠️ Tecnologías
- HTML5 semántico
- Vanilla CSS3 (Clean UI Design Tokens)
- JavaScript nativo (ES6+)
- Despliegue en Hostinger (Node.js Static Web App)

## 📦 Ejecución Local
```bash
# Servir localmente
npx serve .
```
